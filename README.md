## 为什么钱一到就续，而不是落袋为安？

不是冲动消费。这几个月在群里，我真正反复用上的就这几件事：

### 1. 一个词做一个站

先把一个关键词打透，再谈矩阵。国庆 zombie 站就是典型：词缝清楚，壳子够简单，先出最小可付费版，比一上来铺五个域名有用。

### 2. 外链先看 DR，再看是不是真免费

乱提交不如不提交。群里和飞哥、老人天天在抠：这个目录值不值得填、徽章能不能挂、竞品域名有没有坑。我自己后门外链也按这个标准筛，少踩了不少「看起来免费、其实有毒」的坑。

### 3. 排名看的是页面，不是整站

内页、目录页要分开打。以前我会下意识以为「域名权重到了内页就跟着涨」——不对。小课堂和群聊把这个拧回来之后，做站的结构、标题、内链方式都不一样了。

### 4. 信息密度和时间窗口

独立做站最怕的不是不会写代码，是一个人闷头做、错过窗口。国庆那几天，群里新词讨论、谁上了谁出单、支付和 Cloudflare 踩坑，几乎是实时广播。我能在 10/7 看到讨论、当天上线，靠的就是这个密度。

所以奖金到账那天，续费一年对我来说逻辑很简单：

**路径验证过了，工具还在用，人还在群里——续费是继续干活的成本，不是情怀消费。**
